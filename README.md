# Phronesis

The voice and face of Evermore Evolution. Open the page, tap **Wake Phronesis**, and talk.

- Live two-way voice through the ElevenLabs agent (public agent id only; no API keys live in this repo).
- Interrupt him any time; he stops and listens.
- After 10 seconds of silence he rests and the Earth returns. Say "Phronesis" or tap the button to wake him.
